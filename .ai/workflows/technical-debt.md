# Technical Debt Management Workflow

Follow this procedure whenever technical debt is discovered, introduced, or resolved.

---

## Workflow Steps

1. **Discovery & Logging**: Identify trade-offs made during development (e.g. simplified algorithms, synchronous polling).
2. **Schema Formatting**: Document the item using the standardized schema (Debt -> Cause -> Impact -> Priority -> Proposed Resolution -> Status).
3. **Registry Entry**: Add the item to [.ai/state/technical-debt.md](file:///c:/Users/user/Desktop/ug-swe-exams/.ai/state/technical-debt.md).
4. **Prioritization Audit**: Periodically review debt items during examination review.
5. **Resolution Logging**: When a technical debt item is resolved, update its status to `Resolved` and record the resolution date.
